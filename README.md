# Firmá Fácil

Página web para hacer una firma y firmar documentos PDF, todo desde el navegador.

- Dibujar la firma con el dedo, lápiz o mouse, o escribirla con letra manuscrita
- Elegir color de tinta (azul, negro, verde) y grosor
- Descargar la firma como PNG sin fondo
- Subir un PDF, ubicar la firma en una o varias páginas y descargar el PDF firmado

El PDF se procesa en el dispositivo y no se sube a ningún servidor.

**Aviso:** es una firma electrónica (imagen de la firma). No reemplaza a la firma digital con certificado de la Ley 25.506.

Sitio: https://jr8969662-beep.github.io/facil-firma/
